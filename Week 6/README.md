# Week 6 — Transformers & Hugging Face

## Overview

The sixth week introduced transformer-based models and the Hugging Face ecosystem for working with modern natural language processing (NLP) models.

The focus was on understanding the basic architecture and purpose of transformers, loading pretrained language models, generating text, controlling generation parameters, and understanding the fundamentals of fine-tuning. Practical work was then used to apply these concepts through a small text-generation or chatbot workflow.

## Topics Covered

* Introduction to transformer models
* Hugging Face ecosystem and Transformers library
* Pretrained language models
* Loading and using GPT-based models
* Text generation with pretrained models
* Generation parameters such as temperature and maximum length
* Tokenization and model inputs
* Fine-tuning fundamentals
* Adapting pretrained models using a small dataset
* Practical text-generation and chatbot workflows
* Understanding the difference between pretrained inference and fine-tuning

## Practical Work

The concepts were reinforced through hands-on experiments with pretrained transformer models using the Hugging Face Transformers library.

The practical work involved loading a pretrained language model, preparing text inputs, generating responses, and experimenting with generation parameters to observe their effect on the generated output.

Fine-tuning was also studied at a fundamental level using a small dataset to understand how a pretrained model can be adapted to a specific type of text or task.

A small text-generation/chatbot workflow was then developed to combine the concepts into a practical application.
