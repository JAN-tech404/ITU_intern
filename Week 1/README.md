# Week 1 — Python Fundamentals

## Overview

The first week established the Python programming foundation required for subsequent work in data processing, machine learning, and computer vision.

The focus was on developing practical proficiency with Python's core language features, data structures, program control, functions, and file-based data handling.

## Topics Covered

* Python syntax and program structure
* Variables and fundamental data types
* Lists, tuples, dictionaries, and sets
* Conditional statements and loops
* Logical and comparison operators
* Functions, parameters, return values, and scope
* Lambda functions and built-in functions
* Text and CSV file handling
* Basic exception handling

## Practical Work

The concepts were reinforced through a series of hands-on Python exercises and small programming tasks. Particular emphasis was placed on writing reusable functions, manipulating structured data, and working with persistent data stored in text and CSV files.

These exercises established the programming skills required for the later machine learning and computer vision stages of the internship.
