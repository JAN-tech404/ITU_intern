# Week 2 — NumPy, Pandas, Matplotlib & OpenCV

## Overview

The second week focused on developing practical skills for working with data and images using Python's core data-science and computer-vision libraries.

The work introduced NumPy for numerical computation and array manipulation, Pandas for structured data analysis, Matplotlib for data visualization, and OpenCV for fundamental image-processing operations.

## Topics Covered

* NumPy arrays and array operations
* Array indexing and slicing
* NumPy broadcasting
* Mathematical and statistical functions
* Pandas Series and DataFrames
* Loading and working with CSV datasets
* Data filtering and grouping using `groupby`
* Basic statistical analysis with Pandas
* Matplotlib plots and scatter plots
* Histograms and plot customization
* OpenCV image reading and display
* Saving images using OpenCV
* Image resizing and cropping
* Combining data analysis and visualization workflows

## Practical Work

The concepts were applied through hands-on exercises involving numerical arrays, structured datasets, data analysis, visualization, and basic image processing.

A mini data-analysis workflow was also implemented by loading a CSV dataset, analyzing and filtering the data, generating visualizations, and working with an image using OpenCV. This provided practical experience in combining multiple Python libraries within a single workflow.

The work established the foundation for handling datasets and image data, which are essential for subsequent machine-learning and computer-vision tasks.
