# Week 3 — Machine Learning & Convolutional Neural Networks

## Overview

The third week introduced the fundamental concepts of machine learning and deep learning, with a particular focus on supervised learning, neural networks, convolutional neural networks, and residual network architectures.

The work progressed from traditional supervised learning techniques to increasingly advanced neural-network architectures used for image classification and computer vision.

## Topics Covered

* Supervised learning and its workflow
* Linear regression using scikit-learn
* Logistic regression and classification
* Neural-network fundamentals
* Dense layers and their role in neural networks
* Activation functions
* Introduction to convolutional neural networks (CNNs)
* Convolution operations using `Conv2D`
* Pooling layers
* Flattening and fully connected layers
* Basic CNN architecture
* ResNet architecture
* Residual blocks and skip connections
* Understanding why residual connections help train deeper networks
* Practical image-classification workflows using CNNs and ResNet

## Practical Work

The week began with supervised-learning models using scikit-learn to understand the basic workflow of training models on labeled data.

The focus then shifted toward neural networks and the concepts required to understand deep-learning architectures. CNNs were introduced as specialized neural networks for processing image data, with practical implementation of convolution, pooling, flattening, and classification layers.

ResNet was subsequently explored as a deeper CNN architecture. The concept of residual blocks and skip connections was studied to understand how residual learning helps address optimization difficulties when training deeper neural networks.

The concepts were reinforced through practical image-classification exercises using datasets such as MNIST and CIFAR-10, providing experience with both basic CNN architectures and ResNet-based approaches.
